# Research and release audit

- The NCM paper describes multiscale residual vector quantization, coarse-to-fine generation, and parallel neural decoding. Sections 3.3–3.5 and appendix F describe the core model and implementation details. [Kumbong et al., Next-Concept Modeling](https://arxiv.org/pdf/2610.14162v1)
- The Rust engine follows the published XSum architecture and checkpoint tensor layout. The project is MIT licensed and preserves the upstream MIT notice. [Upstream source and license](https://github.com/HazyResearch/ncm/tree/c70274273f489abc73832b2b98584a8483b6b203) · [Project license](../LICENSE)
- The official weight release is tagged MIT. It includes conditional and unconditional checkpoints. The Rust engine supports the XSum summarization architecture and dialogue checkpoints adapted from it. The official collection has no dialogue checkpoint. [Pinned checkpoint release](https://huggingface.co/hazyresearch/ncm-checkpoints/tree/d342ce8aaea58830eef3b8ad473664673e41f692)
- XSum uses 512 source slots, a 48-position decoder, and nine concept scales with widths 4, 6, 10, 14, 20, 26, 32, 40, and 48. Each scale has 4,096 codes. The Rust Tokenizers vocabulary maps text to IDs, and the released neural encoder and decoder supply the learned latent representations. [Pinned vocabulary](https://huggingface.co/openai-community/gpt2/tree/607a30d783dfa663caf39e06633721c8d4cfcd7e)
- Benchmark prompts and the dialogue smoke corpus are included. Model weights and upstream evaluation data are downloaded separately when needed. Check data terms independently before evaluating on an external corpus or adapting a model. [Benchmark prompts](../benchmarks/prompts.json) · [Smoke corpus](../training/smoke.jsonl) · [Upstream evaluation data](https://huggingface.co/datasets/hazyresearch/ncm-datasets/tree/main/xsum)
