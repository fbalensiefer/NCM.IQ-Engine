# Research and release audit

- [Kumbong et al., Next-Concept Modeling, arXiv v1](https://arxiv.org/pdf/2610.14162v1), sections 3.3–3.5, 4.3 and appendix F. The neural tokenizer uses learned codebooks and a residual latent sum at progressively longer scales. The generator predicts each scale in parallel conditioned on the preceding sum and the source prefix. The decoder predicts text-token logits across the reconstructed latent sequence.
- [Reference source](https://github.com/HazyResearch/ncm/tree/c70274273f489abc73832b2b98584a8483b6b203) is MIT. The vendored model and utility files use namespace-adjusted imports. The root license preserves the upstream notice.
- [Released weights](https://huggingface.co/hazyresearch/ncm-checkpoints/tree/d342ce8aaea58830eef3b8ad473664673e41f692) are tagged MIT. XSum, WMT14 and Sudoku are conditional. TinyStories, OpenWebText and LM1B are released for unconditional evaluation. The official collection includes no dialogue checkpoint.
- [Released evaluation data](https://huggingface.co/datasets/hazyresearch/ncm-datasets/tree/main/xsum) is tagged MIT by the uploader. XSum is sourced from BBC articles, and [WMT](https://www.statmt.org/wmt14/translation-task.html) aggregates multiple corpora. This project redistributes neither data nor weights. Dialogue adaptation takes a user-provided corpus whose usage rights must be established separately.
- XSum uses 512 source slots, a 48-token decoder and nine code scales (4, 6, 10, 14, 20, 26, 32, 40, 48), with 4,096 codes per scale. Its generator uses a GPT-2 text vocabulary and a learned VQ-VAE embedding lookup for the source. Full neural encoding and nearest-code selection are used for reconstruction and training targets. The GPT-2 vocabulary files do not require any GPT-2 model weights.
- The reference evaluation launcher assumes CUDA. For CPU and MPS comparison, the quality path keeps the released model modules and evaluation sampling, and moves the FP64 repetition policy to CPU. Decoder repetition penalties traverse the already computed logits without invoking either neural network per token.
